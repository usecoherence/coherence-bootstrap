M0 Dolt runtime policy (coherence-core-db)

Scope:
- M0 verifies live Rust -> Dolt SQL connectivity and minimal schema/data operations.
- This is runtime verification for core-db groundwork, not final architecture completion.

Prerequisite:
- Dolt binary must be installed and available on PATH.
- Check with:
    dolt version

Startup:
- Start repo-local application Dolt SQL server:
    ./scripts/dolt-start
- The script initializes .dolt for this repository if missing.
- Global `dolt config --global` is NOT required for M0 startup.

Dolt init identity source order:
1) DOLT_AUTHOR_NAME / DOLT_AUTHOR_EMAIL
2) git config user.name / user.email
3) fallback identity:
   Coherence Local Dev <coherence-local-dev@localhost.invalid>

Live verification command:
- Run:
    cargo run -p coherence-core-db -- m0-smoke

Expected success evidence:
- connection_mode: socket
  or connection_mode: tcp_fallback
- counts: specs=<n>, acceptance_criteria=<n>
- m0-smoke: success

Connection policy:
- Socket preferred:
  DOLT_SOCKET (default: .dolt/dolt.sock)
- TCP fallback allowed:
  DOLT_HOST (default: 127.0.0.1)
  DOLT_PORT (default: 3306)
- Database override:
  DOLT_DB

Notes:
- `make tool run` is compile/test/policy validation and should not require live Dolt.
- `m0-smoke` is the live DB verification command.
- Beads embedded Dolt under .beads/embeddeddolt is separate from this repo-local application Dolt DB.
